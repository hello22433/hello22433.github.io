# 블로그 수익화 가이드

이 저장소에는 광고 · 후원 · 제휴 링크를 붙일 수 있는 준비가 되어 있다.
**설정값을 채우기 전까지는 아무것도 출력되지 않는다.** 즉 지금 배포해도 사이트 모습은 그대로다.

---

## 1. 이미 준비된 것

| 기능 | 파일 | 켜는 방법 |
| --- | --- | --- |
| 애드센스 로더 · 소유확인 메타 | `_includes/metadata-hook.html` | `monetization.adsense.id` |
| 본문 하단 광고 (애드센스 / 카카오 애드핏) | `_includes/ad-unit.html`, `_layouts/post.html` | `adsense.in_post_slot` 또는 `adfit.in_post_unit` |
| `/ads.txt` 자동 생성 | `_plugins/ads-txt.rb` | `monetization.adsense.id` |
| 후원 버튼 박스 (글 하단) | `_includes/support-box.html` | `monetization.support.*` |
| 쿠팡 파트너스 고지 문구 | `_includes/support-box.html` | 글 앞머리에 `affiliate: true` |
| 개인정보처리방침 페이지 | `_tabs/privacy.md` | 이미 켜짐 (애드센스 심사 필수 요소) |
| 네이버 서치어드바이저 소유확인 | `_includes/metadata-hook.html` | `webmaster_verifications.naver` |

광고 스크립트는 `JEKYLL_ENV=production` 빌드에서만 삽입된다. 로컬에서 `bundle exec jekyll s` 로 볼 때는 광고가 뜨지 않는 게 정상이다.

---

## 2. 현실적인 기대치부터

과장 없이 말하면 이렇다.

- 애드센스 기술 블로그 RPM(1,000회 노출당 수익)은 보통 **1,000~4,000원** 선이다.
- 월 1만 PV면 **월 1~4만원**, 월 10만 PV면 **월 10~40만원** 정도다.
- 지금 이 블로그는 글이 3편이다. 검색 유입이 쌓이기까지 보통 **3~6개월**이 걸린다.

그래서 순서는 이렇게 잡는 게 맞다.

1. **글을 쌓아 검색 유입을 만든다** (이게 8할이다. 광고 세팅은 30분이면 끝난다)
2. 애드센스 · 애드핏으로 기본 수익을 깐다
3. 트래픽이 붙으면 전자책 · 강의 · 스폰서십 · 외주 문의처럼 **단가가 높은 쪽**으로 옮긴다

개발자 블로그에서 실제로 큰 돈이 되는 건 3번이다. 광고는 "글 쓰는 습관에 붙는 이자" 정도로 보는 게 정확하다.

---

## 3. 단계별 실행 순서

### 0단계 — 유입 측정과 색인 (오늘 30분)

광고보다 먼저 해야 한다. 색인이 안 되면 수익도 없다.

1. **Google Search Console** 등록 → `_config.yml` 의 `webmaster_verifications.google` 에 코드 입력
   → 사이트맵으로 `https://hello22433.github.io/sitemap.xml` 제출
2. **네이버 서치어드바이저** 등록 → `webmaster_verifications.naver` 에 코드 입력
   → 국내 검색 유입은 네이버 비중이 크다. 반드시 해두는 게 좋다.
3. **Google Analytics 4** 만들고 측정 ID(`G-XXXXXXX`)를 `analytics.google.id` 에 입력

### 1단계 — 애드센스 심사 통과 준비

애드센스는 "읽을 가치가 있는 사이트"인지를 본다. 실무상 아래를 맞추면 통과 확률이 크게 오른다.

- [ ] **본문이 충실한 글 20편 이상** (권장. 최소 10편 이상, 한 편당 1,000자 이상)
- [ ] 소개 페이지 — `_tabs/about.md` (초안이 들어가 있으니 본인 이야기로 고칠 것)
- [ ] 개인정보처리방침 — `_tabs/privacy.md` (준비됨)
- [ ] 연락 수단 — 사이드바 이메일 링크 (설정됨)
- [ ] 복사 글·자동 생성 글 없음, 광고만 있는 빈 페이지 없음

### 2단계 — 애드센스 연결

1. [Google AdSense](https://adsense.google.com) 가입 → 사이트 추가 → 게시자 ID(`ca-pub-...`) 확인
2. `_config.yml` 에 입력:

   ```yaml
   monetization:
     adsense:
       id: ca-pub-1234567890123456
   ```

3. 커밋 → 푸시하면 `/ads.txt` 가 자동으로 생성되고, 심사용 스크립트가 모든 페이지에 들어간다.
4. 승인 후 애드센스에서 **디스플레이 광고 단위**를 만들고 슬롯 ID를 넣으면 본문 하단에 고정 광고가 붙는다:

   ```yaml
   monetization:
     adsense:
       id: ca-pub-1234567890123456
       in_post_slot: "1234567890"
   ```

   슬롯을 비워두면 애드센스 **자동 광고**만 동작한다 (자동 광고는 애드센스 콘솔에서 켠다).

### 3단계 — 카카오 애드핏 (선택, 국내 트래픽용)

애드센스보다 심사가 훨씬 관대해서, 승인 대기 중에 먼저 깔아두기 좋다.

1. [카카오 애드핏](https://adfit.kakao.com) 가입 → 매체 등록 → 광고 단위 생성 (`DAN-...`)
2. 설정:

   ```yaml
   monetization:
     adfit:
       in_post_unit: DAN-xxxxxxxxxxxx
       width: 320
       height: 100
     ads_txt_extra_lines:
       - "kakao.com, DAN-xxxxxxxxxxxx, DIRECT"
   ```

애드센스와 함께 쓰면 한 글에 광고가 둘 붙는다. 글이 짧을 땐 하나만 켜는 편이 이탈률에 낫다.

### 4단계 — 제휴 링크 (쿠팡 파트너스 등)

개발 서적, 장비(키보드·모니터·거치대) 리뷰 글과 궁합이 좋다. 단가는 광고보다 높다.

- 제휴 링크를 넣은 글은 앞머리에 `affiliate: true` 를 적는다. 그러면 글 하단에 고지 문구가 자동으로 붙는다.

  ```yaml
  ---
  title: 3년 쓴 키보드 정리
  date: 2026-09-01 10:00:00 +0900
  categories: [Review]
  affiliate: true
  ---
  ```

- **고지는 선택이 아니라 의무다.** 표시광고법상 경제적 이해관계를 밝히지 않으면 제재 대상이 된다. 자동 문구를 지우지 말 것.

### 5단계 — 후원 받기

기술 글은 광고보다 후원이 잘 붙는 경우도 많다. 하나만 켜도 된다.

```yaml
monetization:
  support:
    github_sponsors: hello22433   # GitHub Sponsors 프로필 개설 필요
    buymeacoffee: yourname
    toss: https://toss.me/yourname
```

`_tabs/about.md` 하단에도 같은 문구를 넣어두면 전환이 조금 더 나온다.

### 6단계 — 단가가 높은 수익원 (트래픽이 붙은 뒤)

지금 블로그 주제(동시성 제어, 낙관적 락, AI 코딩 워크플로)는 아래로 확장하기 좋다.

| 수단 | 필요 조건 | 대략적인 단가 |
| --- | --- | --- |
| 전자책 (브런치/리디/텀블벅, PDF 직판) | 시리즈 글 10편 → 재편집 | 권당 5,000~20,000원 |
| 인프런 · 유데미 강의 | 커리큘럼 1개 (10~20강) | 수강생당 수만 원 |
| 유료 뉴스레터 / 멤버십 | 꾸준한 발행 이력 | 구독자당 월 3,000~10,000원 |
| 기업 스폰서십 · 기고 | 월 1만 PV 이상 | 건당 30만~200만원 |
| 외주 · 컨설팅 리드 | 블로그가 곧 포트폴리오 | 프로젝트 단위 |

특히 **외주 · 이직 리드**는 개발 블로그의 가장 큰 실질 수익이다. 소개 페이지에 "무엇을 할 수 있는지"와 연락처를 분명히 적어두는 것만으로도 값이 올라간다.

## 4. 검색 유입을 만드는 글쓰기 체크리스트

수익의 8할은 여기서 갈린다.

- **검색어를 제목에 넣는다.** "낙관적 락은 락이 아니다"(좋은 제목)에 더해, 본문 소제목에 `JPA 낙관적 락 OptimisticLockException` 처럼 실제로 검색되는 표현을 넣는다.
- **에러 메시지를 그대로 적는다.** 사람들은 에러 문구를 통째로 검색한다. 유입이 가장 잘 나오는 글 유형이다.
- **글 앞머리에 `description` 을 쓴다.** 검색 결과 요약문이 되고, 클릭률이 달라진다.
- **주 1~2편, 6개월.** 색인과 순위는 누적이다. 짧게 자주가 길게 가끔보다 낫다.
- **글 하나에 문제 하나.** 여러 주제를 섞으면 어떤 검색어로도 상위에 못 간다.
- **내부 링크를 건다.** 이미 쓴 세 편(동시성 · 낙관적 락 · 레이스 컨디션)은 서로 연결되는 주제다. 서로 링크하면 체류 시간과 색인 모두 좋아진다.

---

## 5. 하면 안 되는 것

- **자기 광고 클릭 금지.** 지인에게 클릭 부탁하는 것도 포함이다. 계정 영구 정지 사유이고, 이 경우 미지급 수익도 사라진다.
- 트래픽 구매, 클릭 유도 문구("광고를 눌러주세요") 금지.
- 제휴 링크 고지 누락 금지.
- 광고를 본문보다 위·아래로 과하게 채우지 말 것. 이탈률이 올라 결국 수익이 준다. 글 하나에 1~2개면 충분하다.
- 개인정보처리방침 없이 광고 게재 금지 (이미 페이지가 있으니 지우지만 말 것).

---

## 6. 설정을 바꾼 뒤

`_config.yml` 을 고친 뒤에는 커밋 · 푸시하면 GitHub Actions 가 알아서 배포한다.
로컬에서 확인하려면:

```bash
bundle install
JEKYLL_ENV=production bundle exec jekyll s   # 광고 코드까지 확인하려면 production
```

`_layouts/post.html` 은 Chirpy 7.6.0 의 원본 파일에 광고 · 후원 블록 두 개만 추가한 사본이다.
테마를 올릴 때는 새 버전의 `post.html` 을 다시 복사한 뒤, `수익화` 주석이 붙은 두 블록만 옮겨 붙이면 된다.
